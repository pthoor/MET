# Support

MET is a community-maintained, open-source project. There is no paid or
guaranteed support channel.

## Getting help

- **Bug reports and check requests**: use [GitHub Issues](https://github.com/pthoor/MET/issues/new/choose) -
  there are templates for a bug report and for proposing a new check.
- **Usage questions**: open a [GitHub Issue](https://github.com/pthoor/MET/issues)
  describing what you're trying to do. Include your MET version, PowerShell
  version, and platform (see the bug report template for the exact fields).
- **Contributing**: see [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) for
  how to add a check, run the test suite, and submit a pull request.

## Security vulnerabilities

Do not open a public issue for a security vulnerability. See
[`SECURITY.md`](SECURITY.md) for how to report one privately.

## Response times

This project is maintained on a best-effort basis. There is no SLA for
issue triage or response.
